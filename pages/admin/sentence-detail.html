Bạn đang chuẩn bị xóa vĩnh viễn 0 câu đã chọn. Hành động này không thể hoàn tác!

📋 Nhập Câu Ghép Hàng Loạt

Hướng dẫn định dạng nhập liệu vào bộ này:
• Mỗi dòng một câu, cách nhau bằng dấu gạch đứng |, dấu phẩy , hoặc phím Tab.
• Định dạng 3 cột chuẩn: Tiếng Trung | Pinyin | Tiếng Việt (hoặc 2 cột: Tiếng Trung | Tiếng Việt để hệ thống tự sinh Pinyin).
• Tự động bóc tách từ ghép và tạo giọng đọc phát âm chuẩn MP3.

📥 Import File Excel vào Bộ Câu

Cấu trúc file Excel:
• Chuẩn 3 cột: Cột A: Tiếng Trung | Cột B: Pinyin | Cột C: Tiếng Việt
• Hoặc 2 cột: Cột A: Tiếng Trung | Cột B: Tiếng Việt (hệ thống tự sinh Pinyin)
* Tự động nhận diện thông minh, bóc tách khối từ và tạo file phát âm MP3 chuẩn.
📄
Kéo thả file vào đây hoặc chọn từ máy tính
Hỗ trợ định dạng .xlsx, .xls, .csv (tối đa 5MB)
